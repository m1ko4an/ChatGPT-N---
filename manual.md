Обзор проекта

ChatGPT-N представляет собой интеллектуальную платформу, объединяющую текстовых чат-ботов, генерацию кода, обработку естественного языка, генерацию изображений и систему хранения данных.

Архитектура проекта разделена на независимые подсистемы:

пользовательский интерфейс;
интеллектуальные модули;
генерация медиа-контента;
подсистемы безопасности.

Каждая подсистема реализована в виде отдельных Python-модулей и снабжена докблок-комментариями для автоматической генерации документации.

Сценарии использования
Сценарий 1: Работа с чат-ботом

Пользователь вводит текстовый запрос в интерфейсе платформы. Подсистема обработки естественного языка анализирует запрос, после чего чат-бот формирует ответ.

Пример результата:

Пользователь: Привет
ChatGPT-N: Здравствуйте! Чем могу помочь?
Сценарий 2: Генерация программного кода

Пользователь вводит описание задачи, а подсистема генерации кода автоматически формирует программный код.

Пример результата:

def bubble_sort(arr):
    n = len(arr)

    for i in range(n):
        for j in range(0, n - i - 1):

            if arr[j] > arr[j + 1]:
                arr[j], arr[j + 1] = arr[j + 1], arr[j]

    return arr
Сценарий 3: Генерация изображений

Пользователь вводит текстовое описание изображения, после чего система создаёт изображение.

Пример результата:

Изображение успешно создано:
«Космический город будущего с неоновыми огнями»
